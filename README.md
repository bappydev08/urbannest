# UrbanNest Beauty

A responsive beauty and skincare storefront built with React, Vite, React Router, Framer Motion and Tailwind CSS v4.

## Brand direction
- Brand: **UrbanNest Beauty**
- Visual identity: vivid blush pink, dusty rose, mauve, cream and burgundy
- Product photography: every product visual contains the UrbanNest Beauty pack label

## Store features
- Homepage with branded hero photography, category shortcuts, promotional banner and 20 featured products
- Shop page with category filters, search, sorting and product cards
- Individual product detail pages
- Shopping cart with quantity controls and local persistence
- About and contact pages
- Responsive desktop and mobile layouts

## Run locally

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The checkout, contact and newsletter forms are frontend demonstrations and need a payment, order and email service integration before accepting real customer transactions.
